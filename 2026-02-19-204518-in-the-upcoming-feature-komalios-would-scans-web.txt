     Parasocial Manipulation Detector — Implementation Plan

     Context

     AI chat responses (Gemini) in RikiCheckInView and ReflectionTimeView
     bypass content scanning and go straight to the child. We need a
     deterministic keyword-based detector that intercepts these responses
     before display, using the existing ContentRiskLevel enum and
     ContentFilterPreferences.parasocialContent field.

     ---
     Step 1: Create Sources/Komalios/Resources/parasocial_signals.json

     JSON config with 6 signal categories. Weights sum to 1.0 (ranked by
     danger):
     - authority_replacement (0.25) — 8 phrases: "don't listen to them",
     "adults don't understand", etc.
     - guilt_induction (0.22) — 8 phrases: "you'd hurt my feelings", "after
      all I've done for you", etc.
     - emotional_dependency (0.18) — 8 phrases: "you need me", "you can't
     do this without me", etc.
     - discouraging_relationships (0.15) — 8 phrases: "they don't care like
      I do", "you don't need other friends", etc.
     - exclusivity_framing (0.12) — 8 phrases: "only I understand you", "no
      one else gets you", etc.
     - persistent_availability (0.08) — 8 phrases: "I'm always here for
     you", "I never sleep", etc.

     No Package.swift change needed — .process("Resources") already covers
     it.

     Step 2: Create 
     Sources/Komalios/Services/ParasocialDetectorService.swift

     Pattern: Follows BlocklistService singleton pattern (bundle-loaded
     JSON).

     Models defined in-file:
     - ParasocialSignalConfig (Codable) — version + categories array
     - SignalCategory (Codable) — id, weight, phrases
     - ParasocialScanResult — score, riskLevel (ContentRiskLevel),
     triggeredSignals, categoryScores dict
     - TriggeredSignal — categoryId, matchedPhrase

     Service:
     - final class (no @MainActor — pure computation)
     - static let shared = ParasocialDetectorService()
     - init(bundle: Bundle = .main) — loads JSON, falls back to empty
     config
     - init(config: ParasocialSignalConfig) — for test injection
     - func scan(_ text: String) -> ParasocialScanResult — synchronous,
     thread-safe

     Scoring logic:
     per-category: min(matchCount / 2.0, 1.0)
     overall: sum(categoryScore * weight), clamped [0, 1.0]
     risk: 0 → .safe, 0.01-0.29 → .low, 0.30-0.59 → .medium, 0.60+ → .high

     Case-insensitive via lowercased() on both text and phrases.

     ---
     Design Decisions

     1. Scan off MainActor, preference check on MainActor — scan() is pure
     computation; appState requires main thread
     2. .gate treated same as .block for chat — no gate UI exists for chat
     responses; redirect message is appropriate for both
     3. Only .high risk filters — requires multiple signals across
     categories (score ≥ 0.60), minimizing false positives
     4. persistent_availability weighted lowest (0.08) — "I'm always here
     for you" is common in benign AI responses; authority_replacement
     (0.25) and guilt_induction (0.22) weighted highest as the most
     dangerous manipulation tactics
     5. Filtered message persisted — child shouldn't see blocked content
     when re-opening conversation history

     heavy signals → response should be replaced with redirect message
